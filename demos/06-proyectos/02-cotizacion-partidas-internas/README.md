# Demo: cotización con partidas internas

## Objetivo

Crear una cotización donde el cliente vea un servicio general, mientras el equipo conserva el detalle interno de horas, materiales, maquinaria y pruebas.

## Caso de negocio

Cotizar la puesta en servicio de una subestación. El cliente debe ver el servicio completo; el equipo necesita controlar el costo real por partida.

## Pasos

1. En **Ventas**, crea una cotización para `Cliente Demo Energia Norte`.
2. Agrega el servicio `Demo - Pruebas electricas y puesta en servicio`.
3. Define el precio total visible para el cliente.
4. En el proyecto relacionado, crea tareas o partidas internas para:
   - Horas de ingeniería.
   - Equipos de prueba.
   - Movilización y viáticos.
   - Pruebas de protecciones.
   - Informe técnico.
5. Registra costos internos mediante cuenta analítica, partes de horas o compras.
6. Revisa que el documento enviado al cliente no exponga partidas internas.

## Resultado esperado

La cotización muestra un servicio resumido y el proyecto conserva el desglose necesario para medir margen y avance.

## Validación

- Cliente ve el precio y el alcance general.
- Responsable interno puede consultar el detalle de costos.
- Cada costo queda asociado al proyecto correcto.

Este caso se basa en la práctica descrita en el mapeo: presentar al cliente un resumen macro y controlar internamente partidas no facturables.
