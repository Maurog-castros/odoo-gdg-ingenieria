# Demo: rentabilidad del proyecto

## Objetivo

Comparar ingresos, compras, horas, gastos y materiales para medir el margen de una obra.

## Pasos

1. Abre el proyecto `Demo - Puesta en servicio Subestacion Energia Norte`.
2. Revisa el presupuesto o valor vendido.
3. Consulta las compras imputadas a la obra.
4. Revisa gastos de terreno, horas y costos de inventario.
5. Compara costos comprometidos contra costos reales.
6. Resta los costos al ingreso facturado o esperado.
7. Registra las desviaciones y define acciones antes del cierre.

## Resultado esperado

El responsable puede responder cuánto se vendió, cuánto se gastó, qué falta facturar y cuál es el margen estimado.

## Validación

- Ingresos asociados al cliente y proyecto.
- Compras y gastos asociados a la obra.
- Diferencia entre presupuesto y costo real.
- Pendientes de cobro visibles.
- Rentabilidad revisada antes del cierre.

La disponibilidad de informes depende de la configuración de cuentas analíticas y de la localización contable.
