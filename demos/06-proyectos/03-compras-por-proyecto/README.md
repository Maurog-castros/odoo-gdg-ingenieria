# Demo: compras imputadas a un proyecto

## Objetivo

Solicitar y comprar materiales o servicios para una obra, dejando cada compra asociada al proyecto y a su presupuesto.

## Caso de negocio

La obra requiere pernos, cables, hormigón y repuestos eléctricos para montaje y pruebas.

## Pasos

1. En **Compras**, crea una solicitud u orden para `Proveedor Demo Equipos Electricos`.
2. Agrega productos o servicios necesarios para la obra.
3. En el proyecto, identifica la partida correspondiente: montaje, pruebas o materiales.
4. Usa la cuenta analítica o el campo de proyecto disponible para imputar el costo.
5. Confirma la orden y registra la recepción cuando corresponda.
6. Revisa el costo acumulado del proyecto.

## Resultado esperado

La compra aparece en el proyecto como costo comprometido o realizado, sin mezclarse con otras obras.

## Validación

- Orden asociada al proveedor correcto.
- Proyecto y partida identificados.
- Recepción trazable.
- Costo visible en el análisis del proyecto.

No confirmes recepciones físicas en una base de producción sin verificar que la compra sea real.
