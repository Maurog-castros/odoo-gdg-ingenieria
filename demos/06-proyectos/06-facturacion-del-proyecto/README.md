# Demo: facturación del proyecto

## Objetivo

Registrar la facturación de una obra de montaje y pruebas eléctricas por avance o por hitos.

## Pasos

1. Abre el proyecto `Demo - Puesta en servicio Subestacion Energia Norte`.
2. Revisa el avance y el hito que se debe cobrar.
3. En **Ventas**, crea una factura para `Cliente Demo Energia Norte`.
4. Agrega el servicio general o el porcentaje de avance acordado.
5. Asocia la factura al proyecto o cuenta analítica cuando la configuración lo permita.
6. Confirma la factura y registra el pago de prueba.
7. Consulta el saldo pendiente y la trazabilidad del cobro.

## Resultado esperado

La factura queda asociada al cliente y a la obra, con el estado de cobro visible para el responsable del proyecto.

## Validación

- Factura emitida por el monto correcto.
- Cliente y proyecto correctos.
- Impuestos revisados.
- Pago y saldo pendientes visibles.

La emisión real depende de la localización contable y la integración tributaria configurada.
